# Use custom theme CSS

You can register and use [custom theme CSS for Marpit](https://marpit.marp.app/theme-css) / [Marp Core](https://github.com/marp-team/marp-core/tree/main/themes#readme) by setting `ThemePath`, that includes relative paths to local files in the current vault.
The registered theme can use by specifying theme name in [`theme` global directive](https://marpit.marp.app/directives?id=theme).

![Theme](pictures/Theme.gif)

Theme.css:

```css
/* @theme your-theme */

@import 'default';

section {
  background: #fc9;
}
```

Slides.md:

```markdown
---
theme: your-theme
---

# Use your own theme

---

# Second Slide
```

Markdown preview will reload updated theme CSS automatically when you edited the registered local CSS file.

## Use a remote theme URL

The top-level `theme` directive may point directly to an HTTP or HTTPS CSS URL instead of a registered theme name:

```markdown
---
marp: true
theme: https://example.com/themes/company.css
---

# Remote theme
```

The plugin downloads and validates the CSS in its operating-system temporary directory. It registers that exact local file with both Marp Core preview and every Marp CLI export mode; neither the theme nor a modified note is written into the vault. Relative and protocol-relative `url(...)`, `image-set(...)`, and CSS `@import` references are resolved against the final HTTP(S) response URL, including redirects. Local or executable resource schemes such as `file:`, `blob:`, and `javascript:` are rejected; embedded `data:` resources remain supported.

Remote themes are cached for no more than five minutes. A shorter server `Cache-Control` lifetime is honored, and expired entries are revalidated with `ETag` or `Last-Modified` when available. `no-cache` forces revalidation and `no-store` removes the downloaded version as soon as preview or export releases it. A failed refresh is surfaced instead of silently exporting with indefinitely stale CSS.

Downloads have bounded size, timeout, and redirect limits. Only HTTP(S) URLs without embedded credentials and CSS-compatible responses are accepted. The source note always retains the original URL directive unchanged; only its temporary rendering snapshot uses the generated local theme name.

Declare a remote theme as a plain or quoted, single-line YAML scalar. YAML anchors, aliases, tags, and folded or block scalar forms are rejected because the temporary snapshot cannot rewrite them without changing their YAML semantics.
